# models_online/ is a pickled estimator, and pickled sklearn estimators carry no
# cross-version compatibility guarantee.

# retrained on the buffer-corrected dataset with the multi-core compute signal. There is

# fail with `ModuleNotFoundError: No module named '_loss'` when it unpickles
# scaling_quantile_models.pkl. Workflows must install from THIS file, not a loose list.
#
# The installable `cetp` package deliberately avoids this whole class of problem: it has no
# runtime dependencies and ships the analytical formula plus models/calibration.json rather
# than a pickle.
#
# results/CANONICAL.md does not load these pickles; it refits everything from the
# corrected dataset inside each fold, so its numbers are unaffected.
