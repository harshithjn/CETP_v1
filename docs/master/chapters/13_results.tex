\textbf{Gate.} On 840 evaluations: BLOCK 66 (7.86\%) of which 45.45\% actually breached (54.5\% false alarms); WARN 748 (breach 13.2\%); PASS 26 (3.1\%, breach 3.85\%) \evFILE\ (\src{results/phase7\_gate\_evaluation.csv}). The README's ``PASS covered 4 of 840'' does not match (\cref{app:issues}).
\textbf{Confidence abstention.} AURC 25.44 for hardware-distance ordering vs 31.15 random; at threshold 0.6, 80\% coverage with selective MAPE 28.13\% (abstain 20\%). Tier MAPEs: conf 1.0 $\to$ 27.03 ($n{=}420$); 0.808 $\to$ 33.43; 0.801 $\to$ 22.97; 0.582 $\to$ 32.22; 0.419 $\to$ 70.66 \evFILE\ (\src{results/confidence\_abstention\_summary\_corrected.json}, \src{confidence\_tiers\_corrected.csv}). The score is not monotone with error.

\section{Study F: concurrency, calibration loop, drift}
\begin{itemize}
\item \textbf{Concurrency} (8-core laptop): elasticity median 0.734, range 0.286--0.984, median $r^2$ 0.944; at 8 clients the runtime error is 41.8\% with the global default and 73.8\% ignoring concurrency; per-query oracle 6.7\% \evFILE.
\item \textbf{Parallelism mechanism} (\src{fix3\_parallelism\_mechanism\_summary.csv}): Pearson $r=0.458$, $p=0.0367$; mean speed-up 1.98 for parallel-plan queries vs 0.99 for serial \evFILE.
\item \textbf{Self-calibration simulation}: held-out MAPE 77.72 $\to$ 15.01 ($n{=}36$; retrain trigger 12); narrative q19 c7i$\to$c5a: error 52.85 $\to$ 18.02, confidence 0 $\to$ 1, WARN $\to$ PASS \evFILE. This is a simulation on the same data, not a deployment.
\item \textbf{Cold start} (docs): 15.84 uncalibrated; 13.20 after one well-chosen query; 19.51 after one random query \evCLAIM.
\item \textbf{Plan drift}: plan divergence is 70.5\% of the cross-environment difference when the plan changes; across PostgreSQL 14/15/17/18 about 30\% runtime shift and 12 of 22 plans change \evPACK.
\item \textbf{Learning curve} (machines seen): learned 40.19 ($k{=}1$) $\to$ 30.51 $\to$ 29.86 $\to$ 28.10 ($k{=}4$) against that file's own naive baseline 23.03 (canonical naive-linear: 23.05; the two use slightly different baselines); the learned model needs more machines than exist \evFILE.
\item \textbf{Learned model with plan features}: LOQO hw-only 16.10, base 17.29, base+plan 13.86, plan-only 13.29; LOMO hw-only 25.45, base 23.90, base+plan 23.33, plan-only 24.77 \evFILE\ (plan features help for unseen queries, not unseen machines).
\end{itemize}
