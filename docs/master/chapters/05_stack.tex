\section{Dependency risks}
\begin{itemize}
\item \textbf{Pickle coupling} between scikit-learn versions affects only the Gen-1 gate and research
  scripts. \src{models/PROVENANCE.json} states the pickles were rebuilt under 1.8.0.
\item \textbf{PostgreSQL version.} Plans change between 14/15/17/18 (12 of 22 TPC-H plans), and the
  decomposer's operator map was extended after a corpus sweep found \texttt{BitmapAnd} unmapped
  (\src{plan\_nodes.py} lines 46--52). A future PostgreSQL release introducing a new node type would
  silently land in the unmapped residual, which is reported but not an error.
\item \textbf{\texttt{pg\_hint\_plan} silently ignores hints it cannot express}, which is why the code
  carries \texttt{plan\_forced=False} and a LOW trust flag (\src{cross\_env.py} lines 26--28, 191--192).
\end{itemize}
