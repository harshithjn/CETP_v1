\section{Security and privacy}
\subsection{Threat model (as implemented)}
The only sensitive material CETP handles is the content of query plans, which embed literals (\texttt{Filter: (email = 'x@y.com')}), schema names and, in \texttt{auto\_explain} logs, entire statement text. The design response is
\emph{redact before the data leaves the machine}, with verification (\texttt{assert\_clean}) and an architecture that has no network component. No authentication, authorisation or encryption layer exists because there is no server.

\begin{honest}
The privacy design is thoughtful (redact first, verify, forbid keys) but its verifier is the weak link: a control that returns True on a leaking plan is worse than none because it creates confidence. This should be fixed before any claim of ``PII-safe'' is made.
\end{honest}

\section{Reliability}
\begin{itemize}
\item \textbf{Crash safety.} Calibration store and telemetry rewrite via temp file + \texttt{os.replace}. Appends to the JSONL log are not atomic but each line is independent and a corrupt line is skipped.
\item \textbf{Graceful degradation.} Corrupt store $\to$ zero-shot; missing calibration $\to$ factor 1.0; unparseable log entry $\to$ dropped.
\item \textbf{Concurrency.} No locks anywhere (risk R3). Two processes calling \texttt{save()} can drop each other's observation.
\item \textbf{Determinism.} Seeds are fixed (42) and the canonical outputs were byte-identical across two runs \evPACK.
\item \textbf{Failure transparency.} Predictions carry \texttt{warnings} and \texttt{trust}; refusals have actionable messages.
\end{itemize}

The cost that matters in practice is not computation but \emph{measurement discipline}: probes taken on a busy host changed the parallel speed-up by 48\%, which changes every parallel-node prediction.

\section{Scalability}
Prediction is linear in plan size and independent of data size. The model assumes one query at a time; concurrency is a coarse power law. There is no multi-tenant story beyond ``one calibration file per project''. Nothing was measured on large schemas or SF10 (blocked by disk, per the probe comments).

\section{Compliance and licensing}
No licence file was inspected in this audit (\evUNK). The repository vendors or references third-party data (IMDB, JOB queries, TPC-DS kit, \texttt{pg\_hint\_plan}) under \texttt{data/external}; their licences were not reviewed. Using TPC-H/TPC-DS data for published results has TPC fair-use rules that the project should check before publication.
