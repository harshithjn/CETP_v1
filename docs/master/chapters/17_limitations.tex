\section{Evidence-integrity finding C10 and its fix}\label{sec:c10}
\textbf{What happened.} The Gen-2 evaluation script read every file in \texttt{data/container\_grid/} and every cell in the signature file. When four x86 runner cells were added for the cross-ISA study, the ``8-cell container grid'' silently became a 12-cell mixed-ISA grid (2{,}904 pairs; naive 54.03\%, operator 29.70\%). Independently, the committed outputs (operator 24.95\%) had been generated from an older probe state than the signature file committed beside them. \textbf{Fix} (by the evidence-pack author, uncommitted): cell list now comes from \texttt{grid\_manifest.json}; input SHA-256 hashes are written into the result; a new 11-test file locks selection, hashing, regeneration and determinism; results regenerated (operator 22.41\%). \textbf{Consequence for readers:} quote 22.41 / 22.23, not 24.95 / 24.58; in the working tree the paper draft and \texttt{docs/index.html} already carry 22.41, but \texttt{docs/guides/HANDBOOK.pdf} and \texttt{docs/design/LLD.pdf} still print 24.95 / 24.58 and \texttt{docs/results/laptop\_to\_prod.pdf} still reports the older 132-pair result (28.54\% vs 38.22\%) (text extraction, audit pass \evRUN).
\textbf{Lesson:} any evaluation script that selects its inputs by directory listing is a latent integrity bug.

\section{Future work}
\subsection{Immediate (hours to days)}
Fix the CLI bypass and add its test; regenerate shipped warning strings from metrics; fix the redaction verifier and add adversarial cases; \texttt{git add} \texttt{data/plans\_grid}; update README counts (119 tests; PASS count); decide the documentation source of truth.
\subsection{Medium term (weeks)}
Replace the always-1.0 regression ratio by a Gen-2 plan-structure ratio and measure detection accuracy on labelled before/after pairs; wire Gen 2 into the extension and CI; run on a managed PostgreSQL instance and on real x86 production hardware; add file locking; validate the cardinality term with SF10 data (needs disk).
\subsection{Long term (research)}
Extend to more ISAs and instance families (the x86 runner cells are nearly identical machines); an I/O axis that actually measures storage (needs a table larger than RAM); learned plan-aware models trained on many machines; plan-change prediction; a systematic literature review to establish novelty.
