\section{Reading order for a new contributor}
\begin{enumerate}
\item \src{README.md}, then \src{results/CANONICAL.md} (one hour).
\item \src{cetp/plan\_nodes.py} then \src{cetp/operator\_model.py}: the whole Gen-2 idea is about 450 lines.
\item \src{tests/test\_operator\_model.py}: it is the best executable specification of the model.
\item \src{cetp/cross\_env.py} for refusals and trust.
\item \src{scripts/analysis/canonical\_evaluation.py} \texttt{run\_cv} (line 239): how folds and leakage are handled.
\end{enumerate}

\section{Hazards in the tree}
\begin{itemize}
\item \texttt{data/raw\_buggy\_do\_not\_use/} holds the original, buffer-inflated dataset; the name is the
  warning (the bug summed buffer counters across the tree, inflating them 3.06--12.00$\times$).
\item \texttt{data/plans\_grid} (1.1\,MB) is untracked and git-ignored, so a fresh clone cannot rerun the
  per-operator evaluation (\evPACK, risk list).
\item \texttt{cetp\_measurements\_addition7\_demo.db} at the root is a SQLite demo database from the
  online-learning experiment.
\item \texttt{scripts/docs/} cannot rebuild most of the documentation: it renders Markdown to PDF, and in HEAD only \texttt{README.md} survives (the working tree adds untracked \texttt{docs/README.md}, \texttt{docs/research/*.md} and \texttt{results/CANONICAL.md}).
\end{itemize}
