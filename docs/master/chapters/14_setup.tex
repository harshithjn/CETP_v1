\section{Install and smoke test}
\begin{lstlisting}[language={},mathescape=false]
cd CETP
python3 -m venv .venv && . .venv/bin/activate         # inferred
pip install -e .                                       # CODE: used by cetp-regression-check.yml; no deps
python3 -m cetp.cli selftest                           # RUN: "selftest PASSED"
pip install -r requirements.txt                        # for research scripts/tests
python3 -m pytest tests -q                             # PACK: 119 passed
\end{lstlisting}
The selftest prints five lines (redaction, Gen-1 prediction, regression identity, calibration file, operator model) and exits 0. A \emph{non-editable} install does not work: the wheel carries no \texttt{tests/} or operator registry (\cref{ch:interfaces}; \evRUN). The live harness additionally needs \texttt{psycopg2-binary}, which is in \texttt{pyproject.toml}'s \texttt{research} extra but not in \texttt{requirements.txt}.

\section{Configuration}
Environment variables: \texttt{CETP\_CALIBRATION\_PATH} (store location), \texttt{CETP\_TELEMETRY\_PATH} (default \texttt{\textasciitilde/.cetp/telemetry.jsonl}; \src{cetp/telemetry.py}:40--41), \texttt{PGDATABASE}, \texttt{MACHINE\_ID} (Makefile). Files: \src{gate/cetp.yml} (machine signatures
and SLAs), \src{models/phase7\_gate\_config.json}. Defaults are listed in \cref{app:config}.

\section{Operations}
\begin{itemize}
\item \textbf{Monitoring.} None built in. Telemetry rows and \texttt{Telemetry.summary()} give predicted-vs-actual MAPE next to the naive baseline once actuals are recorded.
\item \textbf{Upgrades.} Re-probe machines after a PostgreSQL major upgrade (rates are per server version). Do not mix probe records with different \texttt{probe\_scale}.
\item \textbf{Backups.} Back up \texttt{\textasciitilde/.cetp/} and the registry JSON.
\item \textbf{Cost.} Prediction is free; probing needs minutes of idle machine; calibration queries run on production.
\end{itemize}
